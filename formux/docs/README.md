# Documentation

These guides describe the current public API of `formux` 2.1.2 and the companion `flutter_formux` package as found in this repository. They document observed behavior; proposals for changes are separate.

1. [Core inputs and forms](core.md): write validators, inspect error state, and use form methods.
2. [Cubit and server errors](state-and-errors.md): state copies, callback order, field errors, and error codes.
3. [Flutter inputs and components](flutter-components.md): available concrete inputs, widgets, localization, and theme integration.

Start with the [root README](../README.md) for a small example. The [improvement proposal](proposals/core-api-and-documentation.md) records behavior that may change in a future release.

The `flutter_formux` component catalog reflects the sibling package's current source. Its release version may differ from the source checked out alongside this package.
